# Martelier

A responsive luxury event design and décor website for Martelier, serving
Dallas, the DMV, and beyond.

## Highlights

- Editorial luxury art direction
- Responsive layouts for desktop, tablet, and mobile
- Services, process, founder, contact, and inquiry experiences
- Accessible navigation and form controls
- Social-sharing metadata and branded preview artwork

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project uses Next.js and is ready to import into Vercel from GitHub.
